# 张灵霄 · 好奇发生处

个人网站：https://lingxiaozhang01.github.io/

React、TypeScript、Vite、Tailwind CSS 与 Motion。源码位于 src/，公开图片位于 public/assets/。

## 更新网站

1. 使用 Node.js 22 或更新版本，运行 npm ci。
2. 修改 src/data.ts 中的内容或 src/App.tsx、src/styles.css 中的展示。
3. 运行 npm run build:pages，生成 docs/ 并禁用 Jekyll。
4. 提交源码和 docs/，推送到 main。GitHub Pages 自动发布 main 分支的 /docs 目录。

仓库和 GitHub Pages 保持启用时，网站独立于本机运行。外部文章、Demo 和飞书文档按各自权限和服务状态访问。
